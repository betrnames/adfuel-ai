# AdFuel.ai

**AI-powered advertising agency site** — campaign management across Google, Meta, TikTok, LinkedIn, and more. Marketing lander with services, portfolio, pricing, and contact.

![AdFuel open graph](public/og.png)

## What it does

- Full marketing site for an AI ad-ops brand  
- Services, social proof, pricing, FAQ, contact  
- Branding / Twitter header utility pages  
- React SPA with Tailwind  

## Stack

| Layer | Tech |
|-------|------|
| Frontend | React, TypeScript, Vite, Tailwind |
| Backend (optional) | Supabase (if wired for forms) |
| Hosting | Vercel / static |

## Quick start

```bash
npm install
npm run dev
npm run build
```

## Repo layout

- `src/pages/` — Home, legal, branding  
- `src/components/` — Hero, Services, Portfolio, Pricing, Contact  
- `public/og.png` — social preview  
- `public/flame.svg` — brand mark
